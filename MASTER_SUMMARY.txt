🚀 HOW TO USE THE SYSTEM
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

METHOD 1: WEB INTERFACE (Primary)
1. Navigate to: /admin/invoice/generator
2. Or click: Addons → Invoice Generator in sidebar
3. Fill in company information (name, email, phone, address)
4. Upload logo (optional, PNG/JPG, max 2MB)
5. Fill in client information
6. Set invoice number and dates
7. Choose theme color (click any color swatch)
8. Add items/services (click "+ Add Item")
9. Set tax rate and discount (optional)
10. Add notes/terms (optional)
11. Click "Generate PDF Invoice"
12. PDF downloads automatically!

METHOD 2: COMMAND LINE (Testing)
# Generate test invoice with default blue theme
php artisan invoice:test

# Generate with specific theme color
php artisan invoice:test --theme="#10b981"

# Generate all theme variations
bash generate-demo-invoices.sh
